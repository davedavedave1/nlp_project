Download the triviaqa dataset from: https://nlp.cs.washington.edu/triviaqa/data/triviaqa-rc.tar.gz

Add the following files from triviaqa to this folder: wikipedia-train.json, verified-wikipedia.dev.json

Execute the script create_partition.py from inside this folder (NOT FROM OUTSIDE OR IT WILL NOT WORK)

==> You will get the New Trainingdata (wikipedia-train_new.json) and the validation set (wikipedia-validation.json).
We will Use verified-wikipedia-dev.json as our test data

Also, create a folder named evidence in this folder. Then copy the wikipedia evidence (whole folder) from the triviaqa dataset into the evidence folder in this folder.
